## 🚀 如何使用

### 方式一: 使用 Android Studio
1. 打开 Android Studio
2. 选择 "Open an Existing Project"
3. 导航到 `KiddoCode-Unified/legacy/KiddoCode`
4. 等待 Gradle 同步
5. 连接设备或启动模拟器
6. 点击 "Run" 按钮

### 方式二: 构建 APK
- Debug APK: Build → Build Bundle(s) / APK(s) → Build APK(s)
- Release APK: 需要配置签名密钥
